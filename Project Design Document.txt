- **Original Plan**: Euler angles (KISS principle)
- **Current Implementation**: Rotation matrices directly
- **Benefit**: Avoids gimbal lock, cleaner math

## Implementation Notes & Discoveries

### Transform System Notes:
- Changed from Euler angles to rotation matrices
- `_affine_transform`: LHS * RHS multiplication
- `_affine_inverse`: R^T and -R^T * T for inverse
- Using np.eye(3) for identity rotation matrix

### OpenGL Patterns Established:
- Clear COLOR | DEPTH buffers at frame start
- Bind VAO → Use Program → Set Uniforms → Draw → Unbind
- Conditional debug logging to reduce spam
- Default to safe values on error (ortho projection)
